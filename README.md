# X-MAP: Explainable Multimodal Fake News Detection

X-MAP combines DistilBERT text features and ResNet-50 image features through concatenation and a classification head. LIME explains text contributions while keeping the paired image fixed; Grad-CAM explains image regions.

The research paper is [X-MAP: An Explainable Multimodal Analysis Pipeline for Efficient Cross-Modal Fact-Checking](paper/xmap_paper_CONFERENCE%2B%281%29.pdf).

## Research configuration and reported results

The experiments use a stratified subset of 15,000 posts from Fakeddit's `test_public.csv`. Duplicate-aware grouping joins normalized/exact titles, shared image URLs, and near-duplicate titles (character TF-IDF cosine similarity >= 0.90). `StratifiedGroupKFold` keeps these groups within one partition. The paper reports 10,624 training, 1,476 validation, and 2,900 test posts, replacing the earlier random split.

Training uses class-weighted cross-entropy, differential learning rates, partial encoder freezing, image augmentation, and selection by validation F1. Images are named by submission `id`, not row position. Missing or unreadable images use a zero tensor; the notebook separately audits image availability and performance.

These are saved research results from the paper and supplied CSV, not a new training run. The baseline notebook trains text-only models on the same duplicate-aware split and copies X-MAP's scores into its comparison table; update those scores after retraining X-MAP.

## Files

- `X_MAP.ipynb`: main training, overlap audit, duplicate-aware split, evaluation, LIME, Grad-CAM, and deletion-based explanation-faithfulness experiments.
- `X_MAP_baselines_comparison (1).ipynb`: CNN, LSTM, BERT, and DistilBERT comparison.
- `XMAP_Fakeddit.ipynb`: dataset exploration.
- `test_public.csv`: Fakeddit metadata already present in this repository.
- `baseline_comparison_results.csv` and `baseline_comparison_chart.png`: saved model comparison.
- `faithfulness_raw_results.csv`, `faithfulness_summary_table.csv`, and `faithfulness_results.png`: saved explanation-faithfulness measurements and chart.
- `paper/`: supplied conference-paper PDF.
- `requirements.txt`: dependencies for the notebooks.

## Run

Python with a CUDA-capable GPU is recommended; the notebooks were developed for Google Colab. CPU execution is possible but training and explanation experiments can be slow.

```bash
pip install -r requirements.txt
jupyter lab
```

Start Jupyter in the repository root so relative paths resolve correctly. Dependencies are unpinned because the supplied notebooks do not record a complete environment lock; exact numerical reproduction is not guaranteed across package versions, hardware, and image availability.

1. Open `X_MAP.ipynb` and run cells in order. Keep `test_public.csv` in the working directory. Required columns include `id`, `clean_title`, `image_url`, and `2_way_label`.
2. Run the image-download cell to build the stratified subset and download available images into `fakeddit_images/{id}.jpg`. Internet access is needed for source images and pretrained Hugging Face/Torchvision weights. Original image URLs may no longer be available.
3. Run the overlap audit and duplicate-aware re-split before building datasets. Train using the restored training-loop cell, which saves `xmap_model_best.pth` by validation F1. Evaluation loads this checkpoint; later cells copy it to `xmap_model.pth` for explanations.
4. Run evaluation and explanation cells, followed by faithfulness evaluation. These cells write the root-level faithfulness CSVs and chart.
5. Run `X_MAP_baselines_comparison (1).ipynb` in its own kernel from the same working directory. Keep its subset and split settings aligned with the main notebook. Update the X-MAP comparison dictionary if its scores change.

Saved notebook outputs document earlier experiments; running the notebooks replaces those outputs and may produce different scores. This update restores the main training loop that was commented out in the supplied notebook, and corrects baseline references to the actual main-notebook filename. No model was retrained as part of repository preparation.

## Repository scope

Model checkpoints, downloaded images, additional dataset copies, archives, editor caches, manuscript drafts, and collected third-party papers are excluded from this update. Checkpoints are generated by training and are ignored by Git. No pretrained X-MAP checkpoint is distributed here.

The local `fakeddit_project/` prototype is omitted because it uses an older first-5,000-row pipeline and row-index image lookup; it does not implement the paper's final experimental protocol. Use the main notebook for the research implementation.
